# Combined CSV Format Guide
## File: nifty_YYYY-MM-DD.csv

---

## Purpose
Single CSV file containing both Nifty50 spot and options OHLC data for one trading day.
Used as input to the backtest. One file per trading day.

---

## Filename Convention
```
nifty_2026-02-25.csv    ← for date 2026-02-25
nifty_2026-03-01.csv    ← for date 2026-03-01
```
The date in the filename must match the `date` column inside the file.

---

## Columns (exact names, case-sensitive)

| Column       | Type   | Format              | Description                                      |
|--------------|--------|---------------------|--------------------------------------------------|
| datetime     | string | YYYY-MM-DD HH:MM:SS | Candle timestamp (1-minute candles)              |
| date         | string | YYYY-MM-DD          | Trading date                                     |
| spot_open    | float  | e.g. 25463.35       | Nifty50 spot candle open price                   |
| expiry_date  | string | YYYY-MM-DD          | Option contract expiry date                      |
| strike_price | float  | e.g. 25450.0        | Option strike price (multiples of 50)            |
| option_type  | string | CALL or PUT         | Must be exactly CALL or PUT (uppercase)          |
| open         | float  | e.g. 166.85         | Option candle open price                         |
| high         | float  | e.g. 167.20         | Option candle high price  ← used for SL check    |
| low          | float  | e.g. 166.45         | Option candle low price   ← used for Target check|
| close        | float  | e.g. 166.90         | Option candle close price ← used for Time exit   |

## Key Rules

### 1. Row structure
- Every minute has TWO rows per strike: one CALL and one PUT
- spot_open repeats on both rows for the same minute (denormalized)
- Rows are sorted by datetime ascending

### 2. Which strikes to include
- Backtest only ever looks up the ATM strike (spot rounded to nearest 50)
- You must include at least the ATM strike for every minute
- Including ATM ± 50 and ATM ± 100 is recommended to handle spot moves

  Example: If spot = 25463, ATM = 25450
  Minimum required strikes: 25450
  Recommended: 25350, 25400, 25450, 25500, 25550

### 3. expiry_date
- Use the nearest weekly or monthly expiry on or after the trade date
- Must be consistent across all rows in the file
- Format: YYYY-MM-DD (e.g. 2026-03-02 for a Thursday expiry)

### 4. Candle timing
- 09:16:00 is the first candle (matches default ENTRY_TIME)
- 15:15:00 is the last candle (EXIT_TIME)
- One row per minute per strike per option_type
- No gaps — if a minute is missing the backtest skips that candle

### 5. spot_open
- This is the Nifty50 INDEX open for that 1-minute candle
- Used to calculate ATM strike: round(spot_open / 50) * 50
- Only open is needed from spot — high/low/close of spot are not used

---

## How Backtest Uses This File

```
For each minute candle:
  1. Read spot_open → calculate ATM strike
  2. Look up CALL row for (datetime, ATM, 'CALL') → open=entry, high=SL check, low=target, close=time exit
  3. Look up PUT  row for (datetime, ATM, 'PUT')  → same
  4. Apply strategy logic
```

---

## Data Source Priority
When running backtest with --date:
  1. nifty_YYYY-MM-DD.csv  ← checked first
  2. gdfl_data.duckdb      ← fallback if CSV not found
